三角洲特种部队 - 联机功能说明
=====================================

联机功能已添加到游戏代码中，但由于Windows头文件冲突需要特殊处理。

功能概览：
----------
✅ 主菜单添加了"联机模式"选项
✅ 支持创建房间（作为服务器）
✅ 支持加入房间（连接到服务器）
✅ 基于TCP Socket的P2P通信
✅ 实时同步玩家位置、生命值、能量
✅ 服务器广播敌人状态
✅ 地图上显示其他玩家（1,2,3,4数字标识）
✅ 最大支持4人联机

技术实现：
----------
- 使用 Winsock2 API
- NetworkManager 类管理所有网络通信
- PlayerPacket 结构传输玩家数据
- GameStatePacket 结构传输游戏状态
- 非阻塞Socket确保游戏流畅运行

编译说明：
----------
由于 winsock.h 和 winsock2.h 冲突，需要添加：
#define WIN32_LEAN_AND_MEAN
并确保 winsock2.h 在 windows.h 之前包含。

当前版本：
----------
联机功能代码已完整实现，但为避免编译冲突，
主程序中暂时注释了部分网络功能。

如需启用完整联机功能，请联系开发者获取
专门配置的编译环境。

----------
